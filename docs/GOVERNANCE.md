# Governance and releases

This fork is maintained by [@daydalek](https://github.com/daydalek) and builds on
[frankea/Whisky](https://github.com/frankea/Whisky), which continues the original
[whisky-app/whisky](https://github.com/whisky-app/whisky) project.

Changes are reviewed through this repository. Support and diagnostic reports go
to [our Issues](https://github.com/daydalek/Whisky/issues); see [SUPPORT.md](SUPPORT.md).

Version tags trigger GitHub-hosted builds and publish an ad-hoc signed app ZIP.
App upgrades are installed from Releases. The Wine runtime has its own build and
release pipeline in [ge-proton-macos-wine-poc](https://github.com/daydalek/ge-proton-macos-wine-poc).
The maintainer controls releases and repository access.
